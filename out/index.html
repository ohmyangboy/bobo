it's bobo!

万事通式的本地 Agent 工作台。

bobo 把会话提醒、额度、设备状态、技能与智能体管理放进一个 macOS 工作台。抬眼看进度，需要你时提醒一下，点击回到工作窗口。

下载 macOS 版 ↓ · GitHub · 安装说明

macOS 13.0+ · 需要本机安装 Node.js 22.13+ · 开源免费 / MIT

通知岛

会话状态、额度和设备指示常驻屏幕顶部，悬停展开、点击跳回。支持 OpenCode、Codex、Claude Code、omp、DeepSeek Harness 和 Antigravity。

一个窗口，管理日常

  • 额度：Codex、Claude Code、OpenCode Go 与 Antigravity 的用量和重置时间。
  • 设备：CPU、内存、磁盘、进程与网络；查看服务线路延迟和出口 IP。
  • Agents：安装、编辑和更新技能，管理智能体与全局配置；支持 AI 总结和翻译。

点击截图可放大查看。这是持续迭代的个人项目，兼容范围主要覆盖我实际使用的工具，欢迎 fork。
