Claude Code

Claude Code 没有对外的事件流，bobo 读本机 ~/.claude/sessions 的活跃会话注册表（status）与 ~/.claude/projects 的会话日志（标题与目录）：busy 运行中、waiting 等你回答（权限确认 / 要你回答）、idle 已结束；进程退出时还在跑或等回答的按已终止处理。只读，不写任何 Claude Code 配置。

CPU

整机占用率按 2 秒窗口的 CPU 时间差计算，与「活动监视器」同一来源；负载均值是 1 / 5 / 15 分钟的系统运行队列长度。

核心

进程

按 CPU 占用排序。%CPU 取自 ps，是进程生命周期的衰减平均值，与「活动监视器」的瞬时值接近但不完全等价。

内存

已用 = 活跃 + 联动 + 压缩占用 − 可回收，缓存（非活跃页）单独列出，口径接近「活动监视器」；内存压力来自内核。

明细

进程

按常驻内存（RSS）排序。「活动监视器」的实际内存口径通常比 RSS 略大，两者会有出入。

磁盘

按 APFS 容器统计：容器里的所有卷共享同一份可用空间，与 Finder 显示的一致。只读取，不写入任何文件。

支持 owner/repo、Git 地址或本地目录；不指定技能时安装仓库里的全部技能。

我的 Skill

添加任意位置的技能目录，目录里的每个技能会自动链接到 ~/.agents/skills，所有 Agent 立即可用；在文件夹视图里可以单独停用或启用某个技能。同步到 GitHub 后，其他人可以用 npx skills add owner/repo 安装。
